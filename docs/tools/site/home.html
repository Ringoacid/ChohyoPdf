ChohyoPdf

日本語の帳票・文書を作るための、C# 製 PDF 生成ライブラリです。

  • MIT ライセンスのみで提供します（デュアルライセンスではなく、GPL / AGPL でもありません）。商用利用もできます。
  • 外部パッケージへの依存はありません。
  • .NET Framework 4.6.2 以降、.NET Standard 2.0、.NET 8、.NET 10 に対応しています。
  • 禁則処理・両端揃え・均等割り付け・ルビなど、日本語の文書に必要な組版ができます。

申込書や伝票のように決まった位置に印字する帳票は、座標を指定して文字や図形を描く API で作れます。2 つの API は組み合わせて使えます。

作例

どの画像も、ChohyoPdf で出力した PDF です。押すと、作り方を説明した説明書の節を開きます。

レポート 名前付きスタイル、禁則処理と両端揃え、セルを結合した表、画像、グラフ、長い表の自動改ページ 目次 見出しから自動で作り、ページ番号も自動で確定します。前付けをローマ数字にするなど、ページ番号の書式も選べます 座標指定の帳票 均等割り付け、枠に合わせた縮小 グラフ 図形の描画で作る棒グラフと円グラフ ルビ（振り仮名） グループルビとモノルビ。「｜東京《とうきょう》」の記法でも書けます 表のセルの結合 見出しを 2 行にし、縦にセルを結合した集計表

このほか、段組み・脚注・箇条書き・ヘッダーとフッター・透かし・しおり・文書内リンク・透過 PNG・写真の向き（EXIF）の反映などに対応しています。機能の一覧は説明書を見てください。PDF の読み込みと編集はできません（生成専用です）。

GUI デザイナー

画面上で部品を並べて文書や帳票をデザインし、PDF や、同じ PDF を作る C# のコードとして出力できる Windows アプリ（ChohyoPdf Designer）もあります。宛名などをあとから入れる差し込み欄（{顧客名}）や、データの件数だけ行をくり返す表も作れます。
